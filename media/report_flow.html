媒體數據自動化整合流程

運用次世代大語言模型 Gemini API，自動解構 CUE 表與報表，自動化對齊、寫入與可視化分析方案藍圖。

Step 1

前端上傳門戶與檔案驗證

  • 指定媒體下拉選單： 支援分類收集 [Yahoo]、[東森]、[TAMedia] 等媒體規格。
  • 多類型檔案託管： 上傳區支援 PDF、CSV 及 XLSX 多份「媒體CUE表」與「媒體報表」批次上傳。
  • XLSX 單 Sheet 防呆： 限制檔案只能包含單一工作表，保護 Gemini 語義解析一致性。

拖曳檔案至此或點擊選取

通常包含：媒體 CUE 表、媒體實際報表
Step 2

Gemini API 結構化特徵提取

  • 語意空間解析： 針對非結構化 PDF 或複雜多變的 Excel CUE 表進行表格物理定位與行、列關聯映射。
  • 多維特徵抽取： 從雜亂的報表中精準還原出 **核心資訊** 與 **數據預估/走期** 二大模塊、共 16 項資料屬性。
核心資訊 (A~G 欄位)
Media (媒體) Placement (廣告名稱) TA (鎖定條件) Ad Size (尺寸) Format (支援格式) Buy Type (購買方式) R、F (輪替/固定)
預估與時程 (H~P 欄位)
Est. Impressions Est. CTR (%) Est. Clicks Est. Views Period From / To Days (天數) Deadline Remark (備註)

Step 3

BigQuery 高效儲存與對齊

  • 自動化對齊 (Schema Mapping)： 將 Gemini API 抽出的標準 JSON 資料，與 BigQuery 資料表 Schema 建立直接映射與備份。
  • 安全稽核與定時分區： 採用時序分區 (Partition by Ingestion Time)，保障每次匯入的廣告資料不重複，並能追蹤原始版本。

Step 4

BI 可視化、智慧查詢與匯出

  • Looker / Agent 智慧整合： 隨時利用 BigQuery 連結 Looker 作實時監測，或呼叫 BQ Agent 查詢媒體成效。
  • 一鍵導出標準 Excel： 點擊下方按鈕可即時匯出與原稿一致的 campaign 明細，報表欄位對齊如右側所示。
